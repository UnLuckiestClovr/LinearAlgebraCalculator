This is a calculator I made to help me understand how linear algebra works on a fundemental level along with expanding my knowledge.
I use NumPy to speed up functionality that uses lists, though do my best to not use the internally coded Linear Algebra methods it incorporates past basic Matrix Math such as Addition, Subtraction, Scalar Multiplication, etc.
I also used the internal library for transposing matrixes as we are merely swapping rows and columns in the 2d Arrays, which seemed intuitive.
